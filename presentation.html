Introduction
Vatel is a voice agent platform.
An agent answers a call, uses tools, and speaks the result. Businesses use it for booking, questions, and after-hours calls.

Agent
How it works
Four steps. The demo builds them one at a time.
01

Listen

Someone speaks. In the demo, that is a line in the terminal. On a phone, it is the caller.

02

Decide

The model reads the conversation and chooses what to do next. Sometimes the answer is just words.

03

Act

When words are not enough, it calls a tool. The time. A calculation. A meeting on the books.

04

Speak

A voice reads the result back. The tool did the work. The voice only reports it.

04
Agenda
Two parts
Code first. Then the same agent in Vatel.

Code

  • A chat with no tools
  • Then one tool, so the model can do math
  • Then time, math, and booking a meeting
  • Then the same agent, with a voice

Platform

  • A voice instead of the laptop speaker
  • A phone number instead of a keyboard
  • A job: answer, check, book, say it back
  • We build that one live, on the platform
