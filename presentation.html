Introduction
Vatel AI is a platform for building voice agents.
You set the prompt, the voice, and the model. You design the call as a flow, and you give the agent tools, including webhooks into your own code. You test it in the browser, publish a version, and put it on a phone number or a SIP trunk. vatel.ai

Agent
How it works
Speech in, a model, tools, speech out. The demo builds this one piece at a time.
01

STT

Speech-to-text. In the last code demo that is local Whisper on the mic. On a phone, it is the caller.

02

LLM

The model reads the transcript, the prompt, and the tool list, then chooses the next step.

03

Tools

A function call when words are not enough. In the demo: math, the current time, book a meeting.

04

TTS

Text-to-speech. The model's reply is turned back into audio for the caller.
